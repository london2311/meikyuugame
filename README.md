# 無限迷宮 深潜

追跡者から逃げながら、どこまで潜り、どれだけの宝を手にできるか。無限に続く3Dダンジョン探索ゲームです。

**スコア ＝ 獲得ポイント × 到達階層**

## 遊び方

- 階段（青く光る穴）に入ると、一つ下の階へ進みます。迷宮は深くなるほど広くなります。
- 宝は12,500種の組み合わせと、14種の「伝説の秘宝」。深く潜るほど希少な宝が出やすくなります。
- ライトを消すと追跡者に見つかりにくくなりますが、視界も狭まります。走ると足音で気づかれやすくなります。

## 道具

| 道具 | 効果 |
|---|---|
| 光球 | 使うと周囲の追跡者を数秒間怯ませ、動きを止める（最大3個所持） |
| 光輪の護符 | 使うと8秒間無敵。触れた追跡者は怯む（最大3個所持） |
| テレポストーン | 触れると2〜5階層下へ飛ばされる |

## 追跡者

| 階層 | 追跡者 |
|---|---|
| 地下1階〜 | 白面 |
| 地下5階〜 | 多眼の鬼面 |
| 地下10階〜 | 骸王 |
| 地下20階〜 | 深淵の口 |
| 地下30階〜 | 無貌の神 |

4階ごとに1体ずつ増え（最大4体）、深くなるほど速くなります。

## 操作

- PC：WASD 移動 ／ マウス 視点 ／ Shift ダッシュ ／ E 光球 ／ Q 護符 ／ F ライト ／ M 地図 ／ Esc 一時停止
- スマホ：画面左側で移動、右側で視点。右下のボタンでダッシュ・ライト・光球・護符
